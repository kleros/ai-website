# trained on. The guided entry point for agents is /llms.txt.

# INVARIANT — never add a Disallow line to this file.
#   1. A named group below overrides the "*" group entirely for that crawler
#      (RFC 9309 §2.2.1), so a Disallow added under "*" would silently NOT
#      apply to any of them.
#   2. Disallow blocks *crawling*, so the crawler never fetches the page and
#      therefore never reads the X-Robots-Tag or <meta name="robots"> that
#      would have told it not to index.
#   Control indexing in netlify.toml (X-Robots-Tag) and in the page <head>.
#
# The named groups below say exactly what "*" already says. They are kept for
# one concrete reason: Content-Signal is group-local, so a crawler that
# matches its own group never reads the "*" group's signal. Without them,
# ClaudeBot and GPTBot would read "no expressed preference" — precisely the
# crawlers this policy was written for.
#
# Tokens verified 2026-09-07 against each vendor's own documentation. The
# retired Anthropic tokens Claude-Web and anthropic-ai are deliberately
# absent: naming them is a no-op that only signals a copy-pasted file.
